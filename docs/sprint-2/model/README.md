# Khota ML

Khota analyzes sidewalk photos submitted through the app.

## Version 1

Version 1 detects surface damage and curb ramp issues. Each detection includes its location in the photo, a confidence score, and a severity label. See the [Version 1 README](version-1/README.md) for details.

## Notebooks

The [notebooks folder](notebooks/README.md) contains scripts and results from two early experiments on public datasets. RDD2022 tested road damage detection, and Project Sidewalk tested whether an image shows sidewalk damage.
